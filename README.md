## Publicacion en GitHub Pages

1. Sube todo el contenido de esta carpeta al repositorio.
2. Asegurate de que `index.html` quede en la raiz del repositorio.
3. En GitHub, ve a `Settings > Pages`.
4. Elige `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub publique el sitio.

## Nota

La web esta preparada como sitio estatico, asi que funciona sin servidor adicional. Si quieres usar un subdominio propio despues, puedes anadir un archivo `CNAME`.
